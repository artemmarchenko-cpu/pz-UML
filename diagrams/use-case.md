# Use Case Diagram — Система бронювання квитків у кінотеатр

```mermaid
graph TD
  Guest([Гість])
  User([Зареєстрований користувач])
  Admin([Адміністратор])

  UC1(Переглянути розклад сеансів)
  UC2(Зареєструватися)
  UC3(Увійти в систему)
  UC4(Вибрати фільм та сеанс)
  UC5(Обрати місця в залі)
  UC6(Оплатити квиток)
  UC7(Скасувати бронювання)
  UC8(Переглянути свої бронювання)
  UC9(Додати фільм)
  UC10(Управляти сеансами)
  UC11(Переглянути звіт про продажі)

  User --> UC1

  Admin --> UC11
```

## Опис

Система бронювання квитків має три типи акторів:

- **Гість** — може переглядати розклад, реєструватися та входити в систему
- **Зареєстрований користувач** — може бронювати квитки, обирати місця, оплачувати та скасовувати бронювання
- **Адміністратор** — керує фільмами, сеансами та переглядає статистику продажів
